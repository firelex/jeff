# The tracked files of jeff-dev that the public copy, firelex/jeff, leaves out (scripts/publish_mirror.py).
# It names no private adapter: the private names live only in the files it leaves out.
#
# One rule per line; a line starting with # is a comment.
#   path/          every file under that folder
#   **/name/       every file under a folder of that name, at any depth (no tracked file needs to match)
#   path           that one file
#   a pattern      with * or ?, matched against the whole path (* also matches /)
#   open-adapters-only: path/
#                  every file under that folder except those in a subfolder named after an adapter in catalogue/
#   open-imports-only: path/
#                  every .yaml file under that folder whose id: is not an adapter in catalogue/
# Every rule must match at least one tracked file, so a stale rule fails the sync. On top of these rules the sync
# leaves out every tracked file that .gitignore matches, and puts in the files of scripts/mirror-overlay/.
