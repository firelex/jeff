A trading assistant on a market-data desk answers short typed requests about six symbols (SPY, NVDA, AMD, AAPL, MSFT, TSLA) over the last three months of one-minute bars. Each request is a casual chat line from a trader or analyst, usually lower case, often abbreviated, sometimes with typos, naming companies by ticker or by name ("nvidia", "apple", "the s&p"). The assistant picks which of its ten functions to call and fills that function's closed-set arguments; arguments the request does not mention keep their defaults.

Write requests the way real users type them, and include the hard patterns: relative dates ("this quarter", "lately", "since last week"); two tickers in different roles ("is amd tracking nvidia" - the first is measured, the second is the yardstick); several tickers to compare; requests that look like a different function than they are (asking how volatile vs asking for a chart, asking for the worst decline vs asking for stats); questions about the data itself ("what tickers do you have"); and requests that state some arguments and leave others out.
